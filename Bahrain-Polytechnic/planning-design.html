PLANNING & DESIGN

DESIGN BRIEF 01 / 06

Help prospective students find a next step.

The site uses an editorial visual direction: a clear page hierarchy, a sticky navigation bar, a blue-forward palette, large headings and concise content. Each page has a different layout rhythm but shares the same typography, navigation and footer. The registration form is a front-end demonstration only.

VISUAL MOCKUPS & STYLE GUIDE 05 / 06

Make the system
feel coherent.

Each linked page above is the implemented high-fidelity mockup: it shows the actual layout, colour scheme, navigation and interface components rather than a separate concept image.

Colour palette

  • Primary · navy #1D3472
  • Secondary · blue #2868B2
  • Accent · cyan #54D9DF
  • Background · paper #F5F6EF
  • Text · ink #112D46

Typography

Headings: Space Grotesk, with system sans-serif fallback.

Body: DM Sans, with system sans-serif fallback.

Fonts are served by Google Fonts when internet access is available; fallback fonts preserve readability offline.

Reusable components

Sticky navigation, responsive native mobile menu, buttons, topic cards, labelled form fields, visible validation feedback, page mastheads, and a shared footer.

Responsive plan

Desktop: split hero and multi-column cards. Tablet: reduce column count and spacing. Mobile: single-column content, disclosure navigation, stacked form fields and comfortable tap targets.

DESIGN DECISIONS 06 / 06

Made to guide,
not overwhelm.

Blue establishes a calm institutional tone; cyan highlights actions and key details. Short sections, consistent labels, descriptive link text, semantic HTML, keyboard focus styles and reduced-motion support help visitors navigate. The layout is designed to reflow on smaller screens.
