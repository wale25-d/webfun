PROJECT REFLECTION 500–600 WORD REQUIREMENT

From a collection of pages to a usable journey.

This project set out to make an informational website about Bahrain Polytechnic for prospective students. The main design challenge was deciding how to make a multi-page site feel like one coherent experience while giving each page a clear purpose. The plan defined seven routes: a home page, three topic pages, a design plan, a reflection and AI report, and a project overview. Mapping them first clarified the navigation.

As the design developed, the site moved from a conventional set of pages toward a more editorial visual system. The blue-led palette, strong headings, restrained accent colour and repeated navigation create a recognizable identity. Page layouts vary to suit their content: the home page introduces the project and includes the registration form, the study page uses topic cards, and the visit page emphasizes verified contact information. A shared stylesheet maintains common elements; responsive rules adapt layouts to smaller screens.

The registration form was an important implementation lesson. A form can look complete while still failing to validate the assignment’s requirements. The final version checks that first and last names contain at least three characters, the phone field contains exactly eight digits, and the email has a valid format. It gives field-level error messages and a success message. Because this project has no back-end service, the success message says that the details passed local checks; it does not claim that an application was submitted or that data was stored.

The group used Claude, Gemini and ChatGPT as AI-assisted development tools. In the recorded ChatGPT/Codex work, prompts requested a blue-forward Bahrain Polytechnic redesign, the current official logo, a navigation bar that stays visible while scrolling, a modern registration page, and a review against the assessment brief. The generated suggestions were treated as drafts. The site’s page structure, wording, assets, navigation and form behavior were reviewed and adapted into a distinct seven-page coursework project. We checked the stated requirements against the assignment and verified the contact details against official university information before including them.

Using AI responsibly means checking facts, avoiding unsupported claims and being transparent about generated assistance. Official university information was used to verify contact details. The site labels itself as a student project, links visitors to official sources for current admissions information, and explains that its form does not transmit data. The team should also verify image origins and licenses, preserve the real prompt/output evidence, and make sure every member understands and can explain the submitted code.

The process reinforced that responsive design is more than shrinking a desktop layout. Navigation, forms, spacing, images and reading order all need to work at narrow widths. Semantic headings, labels, alt text, visible keyboard focus and reduced-motion support also make the site easier to use. These decisions should be checked on actual devices and with keyboard navigation before final submission.

Group collaboration matters because design, content, implementation and verification depend on one another. Dividing the work into research, design, coding and review gives each member a clear responsibility, while regular check-ins keep the pages coherent. Reviewing the complete site together helps catch navigation gaps, inconsistent content and accessibility issues before delivery. A shared overview of roles and decisions also makes it easier to explain how the work was completed. This project reinforced that collaboration is not only dividing tasks, but also exchanging feedback and bringing each part together into one usable experience.
