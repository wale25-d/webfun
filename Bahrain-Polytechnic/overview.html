ASSESSMENT RECORD

01 / PROJECT OVERVIEW

Website title

Make Learning Matter — Bahrain Polytechnic Student Project

Website category

Educational and institutional informational website

Problem statement

Prospective students need a clear starting point to learn about an institution, explore study topics and find reliable contact and admissions information. This coursework website organizes introductory information and directs visitors to official sources for current details.

Target audience

Prospective students and visitors seeking an introduction to Bahrain Polytechnic.

Project objectives

  • Build a seven-page responsive website.
  • Provide consistent navigation and topic-specific content.
  • Validate the required registration fields in the browser.
  • Document design choices, AI use, sources and limitations.

02 / REQUIREMENT ANALYSIS

Functional requirements

  • Navigate between exactly seven HTML pages.
  • Show an introduction, overview, hero, navigation, CTA and registration form on Home.
  • Require first and last names of at least three characters.
  • Require a mobile number of exactly eight digits.
  • Validate email format and show accessible error/success feedback.
  • Provide working internal links, official source links and an embedded location map.
  • Display planning, reflection, AI usage and project documentation.

Non-functional requirements

  • Performance: static HTML/CSS/JS; images set to content-appropriate sizes; map loaded lazily.
  • Accessibility: semantic landmarks, heading hierarchy, labelled inputs, alt text, visible focus and live form feedback.
  • Security and privacy: no backend, account system, data storage, or transmission; form states this clearly.
  • Usability: concise labels, consistent navigation and obvious next steps.
  • Responsiveness: desktop, tablet and mobile layouts with CSS breakpoints.

05 / UI STYLE GUIDE & RESPONSIVE PLAN

Colour palette

Primary navy #1D3472 ; secondary blue #2868B2 ; cyan accent #54D9DF ; paper background #F5F6EF ; ink #112D46 .

Typography

Space Grotesk for headings and DM Sans for body text, each with system sans-serif fallbacks.

Components

Sticky navigation and responsive disclosure menu; buttons; cards; labelled form inputs; visible validation status; shared footer.

Device layouts

Desktop uses split and multi-column layouts. Tablet reduces columns and spacing. Mobile stacks sections and fields, exposes a disclosure menu, and keeps controls full-width where useful.

08 / ETHICAL & LEGAL PRACTICE

  • Identify the website as a student coursework project, not an official university service.
  • Check factual claims and send visitors to official pages for changing admissions information.
  • Document AI assistance and review generated content rather than treating it as authoritative.
  • Credit media and follow its license. The provided project files do not identify the original creators or licenses of the local photographs; the group must confirm and add those credits, or replace images with properly licensed media before submission.
  • Use the official Bahrain Polytechnic logo only in a context that does not imply university endorsement.
  • Collect no personal information in this static demo; its form validates locally only.
  • Write original content and code, and retain group evidence of contributions and decisions.
